## Promotional text

Plan a session once, confirm attendance, and keep each dog’s progress, package usage, and homework up to date—without a client account or mandatory cloud service.

## Description

DogCoach Studio is a local-first workspace for independent dog trainers.

- Build a private exercise catalog and reusable lesson templates.
- Plan group and individual sessions.
- Confirm attendance and record only individual differences.
- Create an immutable progress history for every dog.
- Track multi-session packages with an append-only ledger.
- Review and export client-facing homework reports.
- Keep trainer-private notes structurally separate from reports.
- Export a complete JSON and CSV backup whenever you choose.

Core workflows work offline. Existing data remains readable and exportable even without an active Pro subscription. DogCoach Studio does not diagnose behavior, provide medical advice, or promise training outcomes.
